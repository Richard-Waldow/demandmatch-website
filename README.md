# demandmatch.io

The public DemandMatch website, served by GitHub Pages from `main` (custom domain in `CNAME`).

The source is developed in the private repo `Richard-Waldow/edel`. To update this site, run there
`node tools/build.mjs && sh tools/publish.sh <path to this checkout>`, then commit and push `main` here.

For agents: https://demandmatch.io/llms.txt
